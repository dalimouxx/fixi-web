# Fixi 18.1.0 — Caisse Windows 0.11.0 : mode atelier (Fixi Pro)

Un seul installateur FIXI Caisse, deux modes : **fournisseur** (inchangé) et **atelier**. Bouton « Je suis un atelier de réparation » sur l’écran de connexion (et « Je suis fournisseur » pour revenir).

## Mode atelier
- Connexion : région → boutique → profil → code PIN à 6 chiffres (les mêmes que sur le web), mémorisés pour la prochaine fois.
- **Réception** : téléphone, nom, marque, modèle, panne (pannes fréquentes en un clic), prix estimé, code de déverrouillage, urgent → dossier créé et **ticket de dépôt imprimé directement** (code, appareil, panne, lien de suivi).
- **À rendre · Encaisser** : appareils prêts ou avec solde, recherche par code/téléphone/nom, encaissement Espèces/Carte/D17/Virement, remise au client en un clic, **ouverture du tiroir-caisse** et **reçu imprimé**.
- **Fin de journée** : encaissé du jour, par moyen de paiement, derniers encaissements, impression.
- **Réservé à Fixi Pro** : un atelier en offre gratuite voit l’écran « Essayer Fixi Pro » (ouvre la page d’essai). Le serveur revérifie l’accès Pro à chaque appel.
- Sécurité : session séparée de la caisse fournisseur ; seuls les appels du comptoir sont autorisés depuis l’application (liste fermée, testée).
