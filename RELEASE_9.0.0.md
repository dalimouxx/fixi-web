# Fixi Web 9.0.0 — Community & Arabic

## Fixi Community
- Chat communautaire global, régional et par spécialité.
- Publications : discussion, panne, solution, compatibilité et alerte.
- Réponses, votes "utile" et confirmations techniques.
- Photos techniques légères dans les publications.
- Knowledge Hub : les contenus confirmés restent recherchables.
- Une compatibilité confirmée par au moins 3 boutiques distinctes peut enrichir automatiquement le Compatibility Hub avec le niveau `COMMUNITY`.
- Lors de l'ajout manuel d'une compatibilité, l'utilisateur peut la partager automatiquement dans Fixi Community.
- Les informations communautaires restent distinctes des compatibilités physiquement vérifiées.

## Français + arabe
- Sélecteur FR / AR disponible sur toutes les surfaces Fixi.
- Préférence mémorisée dans le navigateur.
- Passage automatique LTR / RTL.
- Menus, boutons, statuts, principaux formulaires, landing, Boutique, Control, Supplier, Queue et suivi client couverts.
- Les données utilisateur (noms, références, notes et contenu communautaire) restent des données métier et ne sont pas modifiées.

## UX
- Nouvelle entrée "Communauté" dans le menu atelier pour tous les rôles actifs.
- Landing V9 enrichie d'une section Fixi Community.
- RTL adapté à la sidebar, formulaires, recherche et composants communautaires.
