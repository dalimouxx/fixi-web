# Fixi 18.2.0 — Livreurs partenaires entre fournisseurs

Inclus dans l’abonnement Fixi Fournisseur **actif** (pas pendant l’essai), sans frais par course pour Fixi.

- **Partager mes livreurs** (onglet Livraison) : le fournisseur choisit les livreurs qui acceptent des courses d’autres fournisseurs et leur prix par course.
- **Confier une commande prête** à un livreur partenaire de la même région (nom, fournisseur d’origine, prix affichés).
- Le livreur voit la course dans son application avec le badge « Course pour … · prix · sans encaissement » ; code de remise, photo, signature, GPS et arrivée annoncée fonctionnent comme d’habitude, et le fournisseur qui confie la course suit tout (événements, position, preuve).
- **Argent séparé** : aucun encaissement par le livreur sur une course partenaire (paiement hors livraison), donc la caisse COD de chaque fournisseur reste intacte ; la course est réglée directement au livreur au prix affiché.
