# Fixi Web 10.0.0

## Nouveautés

- Parts Market inter-boutiques.
- SOS Pièce régional/global.
- Expert Call avec échange technique privé.
- Academy + Knowledge Hub communautaire.
- Copilot vocal Réception Express FR/AR.
- Fixi Care et garantie digitale.
- Client Wallet privé.
- Offline Reception + synchronisation idempotente.
- Landing mise à jour pour présenter l’écosystème réseau V10.

## Règles importantes

- Une annonce marketplace ne modifie pas automatiquement le stock boutique.
- Une transaction doit être validée par le vendeur.
- Offline Sync est limité aux opérations sûres de réception ; pas de paiement hors ligne.
- Les données techniques communautaires restent distinctes des informations “vérifiées”.

## Expert Call V10

- Chat privé entre la boutique demandeuse et l'expert qui accepte.
- Pièces jointes photo techniques dans la conversation.
- Lien d'appel vidéo facultatif (HTTPS/HTTP uniquement) pour Meet, Teams, WhatsApp Web ou autre service choisi par les réparateurs.
