# Tests locaux Fixi V9

## Communauté
1. Se connecter avec un utilisateur atelier.
2. Ouvrir `http://localhost:3000/app/community`.
3. Publier une discussion globale.
4. Tester le filtre "Ma région".
5. Publier une compatibilité avec modèle + référence de pièce.
6. Depuis trois boutiques distinctes, cliquer "Je confirme" et vérifier son apparition dans le Compatibility Hub avec le niveau Communauté.
7. Tester une publication avec photo (< 2 Mo).

## Arabe
1. Cliquer sur `AR` dans le sélecteur flottant.
2. Vérifier `dir=rtl` sur la page.
3. Tester Landing, Login, Dashboard, Réception, Caisse, Community, Control, Supplier, Queue et Track.
4. Repasser en `FR` et vérifier le retour LTR.
5. Recharger le navigateur : la langue doit rester mémorisée.
