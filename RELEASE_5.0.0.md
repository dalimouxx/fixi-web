# Fixi Web 5.0.0 — Smart Release

Cette version transforme Fixi en **Smart Repair Business OS**. Elle conserve Fixi Shop, Control et Ads, et ajoute Brain, Insights, automatisations, Smart Pricing/Diagnostic/Technician, prévision de stock, qualité, fidélité, avis, devis client, passeport appareil, rendez-vous, kiosk, marketing intelligent et mode propriétaire.

## Principes
- Les suggestions Smart reposent d’abord sur les données réelles de la boutique et des règles explicables.
- Aucune API IA externe payante n’est nécessaire pour faire fonctionner V5.
- Les actions sensibles restent soumises aux permissions serveur et/ou à validation humaine.
- Les automatisations sont journalisées.
